# Static runtime licenses

The project is Apache-2.0 licensed. The release also includes available upstream
license files for the selected Cargo normal/build dependency graph.

- `MUSL-COPYRIGHT.txt`: musl v1.2.5 COPYRIGHT, fetched from the tagged
  https://github.com/ifduyue/musl/blob/v1.2.5/COPYRIGHT mirror.
- `GCC-runtime-copyright.txt`: GCC 14/libstdc++ copyright and GCC Runtime Library
  Exception text, from the Debian GCC 14 copyright distribution.
- `GPL-3.0.txt`: the GPL text referenced by GCC runtime licensing; the runtime
  exception is included above. This does not change the project's license.
- `Rust-LICENSE-MIT.txt` and `Rust-COPYRIGHT.txt`: Rust 1.89.0 source distribution;
  Rust's Apache-2.0 text is the same standard license supplied as project LICENSE.

The release inventory identifies component versions and source revisions. Build
tool dependencies may be listed in addition to code present in the final binary.
